## What I do

I work where business requirements turn into systems. Currently **System Analyst** for vehicle financing (multifinance) at **SEVA (Astra Group)**, where I design module and API contract structure for the NestJS + TypeORM backend, and trace issues through providers, guards, and interceptors when something breaks.

- **Ship.** Next.js, TypeScript, and Node in production with PostgreSQL underneath. I architected SEVA's multifinance platform from zero to Phase 2 and designed its 105 REST API endpoints across Agency and CMS Agency.
- **Design.** Technical specifications, system architecture, ERD and data models, REST API contracts in OpenAPI 3.0, and the task breakdown that gets them built.
- **Build AI tooling.** Agent skills, LLM orchestration, and local-first apps that turn specifications into working software. Four of them are open source below, and this is the part I would do for free.
- **Teach.** I break down how these things get built, in public, mostly for the Indonesian developer community.
